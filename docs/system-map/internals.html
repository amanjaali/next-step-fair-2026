    Documentation / Behind it

    17

    The dashboard

    One section per area, grouped by what the person doing the work is thinking about. Roles decide what is visible: gate staff cannot open registrations, and a content editor cannot read personal details.

    18

    Data model

    The registration is the hub. Everything a person does — sessions saved, days attended, messages received, universities matched and met — hangs off that one row, which is why a visitor pass can become a full registration without anything being orphaned.

    What is protected, and how

    DataAt restStill searchable because
    Phone numbersEncryptedA keyed hash column sits beside it
    Email addressesEncryptedSame
    QR contentsTicket id plus signature onlyNothing personal is in the code at all
    Press ID uploadsPrivate disk, never publicReached only from the dashboard
    19

    What runs when

    Reminders are scheduled commands, not something anyone has to remember to press. Each one skips anybody who has already had that message, so running it twice cannot double-send.

    CommandDoes
    nextstep:reminders three-days|one-day|day-ofQueues that reminder wave, skipping anyone already sent it
    nextstep:session-reminders15-minute nudges for bookmarked sessions
    nextstep:badges:regenerateRe-renders badge artwork after a design or key change
    nextstep:qr-secretCreates or rotates the QR signing secret
    nextstep:sitemapRebuilds the sitemap across all three languages

    Guards and limits

    Three separate logins that cannot be swapped for one another: an attendee session does not open the portal, and a portal session does not open the dashboard.

    LoginWhoProves it byReaches
    webNext Step staffEmail and password, roles/admin, /checkin
    attendeeAnyone with a badgePhone plus WhatsApp code/me and everything under it
    institutionUniversity recruitersEmail plus code/portal

    Rate limits

    ActionLimitCounted per
    Submitting a registration6 / minute, 40 / dayIP address
    Entering or resending a code5 / minuteIP address, and per ticket
    Requesting a sign-in code5 / minute, 15 / hourIP, and 3 / minute per phone number
    Lead capture forms4 / minuteIP address
    Gate scanning120 / minuteSigned-in staff member

    Every public form also carries a hidden field a real person never fills in, and a signed session token — so the ordinary bot traffic never reaches the database at all.
