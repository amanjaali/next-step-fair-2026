    How to read this

    Seven pages, nineteen sections, one diagram per flow. Each diagram is followed by the files it lives in, so a picture can be traced to the code that makes it true. Colour means the same thing throughout.

    Fair track — students, parents, visitors Conference track — government and officials Exhibitors — universities and institutes Operations — staff, gate, scheduled jobs
    Reading a diagram

    A rounded box is a person. A rectangle is a page or a step. A diamond is a decision. A cylinder is something written to the database. Wide diagrams scroll sideways inside their own frame — the page itself never does.

    The whole thing at a glance

    Four kinds of people use this, and each has their own front door and their own login. They never see each other's screens, but everything they do lands in the same three places: the registration record, the shared taxonomy of subjects, and the message log.

    In the code
    • routes/site.phpEverything under a language prefix
    • routes/web.phpTickets, check-in, webhooks, QR
    • config/auth.phpThe three separate logins
    02

    URLs and language

    Every readable page lives under a language segment — /en/agenda, /ku/agenda, /ar/agenda — so a link can be shared without losing the language it was read in. English is what a first-time visitor gets; after that the choice is remembered for a year.

    In the code
    • app/Http/Middleware/SetLocale.phpResolves and remembers the language
    • app/Http/Controllers/LocaleController.phpSwitcher and the redirect fallback
    • lang/en · lang/ku · lang/arEvery string, three times
